# Garden layout and solar planning

This repository publishes the static recipient-facing wrapper for the adopted Garden v0.15 R5 material.

The site presents:

- 2D garden layout and frozen dimensioned reference;
- validated interactive GLB and static 3D preview;
- scenario-bracketed R4 solar analysis and six distinct solar views;
- project and solar summary PDFs;
- useful planning CSV/JSON evidence; and
- a separately named sanitised public distribution ZIP.

## Claim boundary

The rear bearing is approximately 330° true ±5°. Off-site structures and vegetation are represented as planning scenario brackets. Gum cases are uncertainty cases, not surveyed tree geometry. This material is suitable for garden planning, not survey, construction, fabrication or purchasing use. `ordering_ready=false`.

## Publication boundary

This is a public derivative, not the authoritative source repository. It does not contain source `.blend` files, raw photos, build scripts, runtime logs, credentials or local workstation paths. The exact adopted R5 master remains frozen outside this public repository.
